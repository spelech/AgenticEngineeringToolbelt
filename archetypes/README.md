## ➕ Adding a New Archetype

To contribute a new engineering archetype:
1. Create a new markdown document `archetypes/<archetype-name>.md`.
2. Define the collaboration model, core tenets, backend/frontend stacks, testing methodologies, and CI/CD expectations.
3. Register the archetype in this index.
