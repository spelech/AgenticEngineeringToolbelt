# ⚡ Agent Skills Manifests

The toolbelt provides three executable skills compatible with Antigravity and Claude Code:

## 1. `engineering-archetype`
Enforces Steven T. Pelech's master engineering archetype across all languages.
- Path: `.agents/skills/engineering-archetype/SKILL.md`
- Focus: SOLID, APIs First, Traditional Git Flow, and 3-Tier Testing Cadence.

## 2. `test-harness-builder`
Generates controls-grade simulation and control harnesses for developers and AI.
- Path: `.agents/skills/test-harness-builder/SKILL.md`
- Focus: Diagnostic tap points, high-volume simulation loops, disturbance injection, and 6-part feedback envelopes.

## 3. `scaffold-project`
Automates scaffolding of new repositories conforming to any of the 5 archetypes.
- Path: `.agents/skills/scaffold-project/SKILL.md`
- Focus: Directory layout, configurations, CI/CD, and living documentation baseline.
